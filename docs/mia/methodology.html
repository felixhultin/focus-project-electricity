Method and sources

The 127 target terms and 91 Korp corpus IDs come from workbook filenames in data/mia. Multiword targets are queried as consecutive lemma tokens.

Absolute frequency is the number of lemma matches. Relative frequency is matches per million tokens. Korp API v8 /count_time supplies yearly hits and /timespan supplies yearly token totals. Both use time strategy 3, and the site aggregates them by decade.

The workbook export contains more than 22 million rows. Counts and source breakdown totals use all rows. To keep the combined GitHub Pages site practical, the example browser publishes up to 100 excerpts per word, resource, and decade. The displayed Korp and workbook counts remain exact.

The author and newspaper page uses Korp statistics grouped by structural metadata. Per-million author rates use author token totals for the selected date scope. Newspaper totals use the same time settings as the plots.

Source: Språkbanken Korp API v8. provenance.json records the corpus and query settings.

Kvinnsam journals

The supplied target-usage exports cover Dagny, Framåt, Hertha, Idun, Morgonbris, Tidevarvet and Tidskrift för hemmet. Each JSONL record counts as one exported match. Dates come from the export metadata; undated matches remain visible in the example browser but do not appear in dated plots.

All exported records contribute to counts. The example browser keeps a deterministic reservoir sample of up to 100 excerpts per term and decade (seed 42). Journal breakdowns use every record. Kvinnsam has no supplied corpus token totals or corresponding Korp API counts, so no per-million rate or API difference is calculated. Source links open public page images from files.ub.gu.se.
